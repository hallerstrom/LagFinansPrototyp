# LagFinans – klickbar prototyp

Exempel: **IK Franke P90**

## Starta lokalt

```bash
npm install
npm run dev
```

Öppna sedan adressen som Vite visar, normalt `http://localhost:5173`.

## Innehåll
- Rollväxling mellan Förening, Lag och Förälder
- Dashboard med exempeldata
- Projekt, finansiering och deltagare
- Rapporter och spårbarhet
- Responsiv layout

Detta är en frontend-prototyp. Ingen data sparas och inga riktiga betalningar görs.
